# Web3 ARB Transfer Application

Web3-приложение для перевода ARB токенов в сети Arbitrum Goerli Testnet.

## 🎯 Описание

Одностраничное приложение, которое позволяет:
- Подключать кошелек MetaMask
- Проверять подключение к сети Arbitrum Goerli
- Отправлять ARB токены на другой адрес
- Просматривать транзакции в Arbiscan

## 🛠️ Технологии

- **TypeScript** + **React** - основной стек разработки
- **Vite** - сборщик и dev-сервер
- **Tailwind CSS** - стилизация
- **shadcn/ui** - UI компоненты
- **Ethers.js** - взаимодействие с блокчейном
- **Arbitrum Goerli** - тестовая сеть (Chain ID: 421613)

## 📋 Требования

- Node.js (версия 18 или выше)
- npm или yarn
- MetaMask (расширение для браузера)

## 🚀 Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd web3-wallet-copilot
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите dev-сервер:
```bash
npm run dev
```

4. Откройте приложение в браузере по адресу `http://localhost:5173`

## 🔧 Настройка MetaMask

### Добавление сети Arbitrum Goerli

Приложение автоматически предложит добавить сеть при первом подключении. Альтернативно, можно добавить вручную:

**Параметры сети:**
- **Название сети:** Arbitrum Goerli
- **RPC URL:** https://goerli-rollup.arbitrum.io/rpc
- **Chain ID:** 421613 (0x66eed)
- **Символ валюты:** ETH
- **Block Explorer:** https://goerli.arbiscan.io

### Получение тестовых токенов

1. **ETH для Goerli:**
   - Получите Goerli ETH из фаусета: https://goerlifaucet.com/

2. **Bridging в Arbitrum Goerli:**
   - Используйте официальный мост Arbitrum: https://bridge.arbitrum.io/
   - Переключитесь на Goerli Testnet
   - Отправьте ETH с Goerli на Arbitrum Goerli

3. **ARB токены:**
   - ARB токены доступны на Arbitrum Goerli
   - Адрес контракта: `0xE591bf0A0CF924A0674d7792db046B23CEbF5f34`

## 💻 Использование

1. **Подключение кошелька:**
   - Нажмите "Подключить кошелёк"
   - Подтвердите подключение в MetaMask

2. **Проверка сети:**
   - Если вы не в сети Arbitrum Goerli, нажмите "Переключить сеть"

3. **Отправка токенов:**
   - Введите адрес получателя (формат 0x...)
   - Укажите сумму в ARB
   - Нажмите "Отправить"
   - Подтвердите транзакцию в MetaMask

4. **Просмотр транзакции:**
   - После успешной отправки появится ссылка на Arbiscan
   - Нажмите на ссылку для просмотра деталей транзакции

## 🔒 Безопасность

- Приложение использует только официальные библиотеки (ethers.js)
- Приватные ключи никогда не покидают кошелек MetaMask
- Все транзакции требуют подтверждения пользователя
- Валидация адресов и сумм перед отправкой

## ⚠️ Важные замечания

- Это тестовое приложение для Arbitrum Goerli Testnet
- Не используйте реальные средства
- ARB токены в тестовой сети не имеют ценности
- Убедитесь, что у вас достаточно Goerli ETH для оплаты газа

## 🐛 Известные проблемы

- Если MetaMask не открывается автоматически, проверьте, не заблокированы ли всплывающие окна
- При смене аккаунта в MetaMask страница обновится автоматически
- Баланс обновляется после каждой транзакции
